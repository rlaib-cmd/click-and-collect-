# Splash360 Commande

Application de commande en ligne en marque blanche (Click & Collect et livraison) pour les enseignes Splash360 : application client iOS, Android et web (Expo), back-office (Next.js) et serveur de commande (Hono), paiement Stripe Connect.

- Cahier des charges : [`docs/cahier-des-charges.md`](docs/cahier-des-charges.md)
- Consignes de développement et commandes : [`CLAUDE.md`](CLAUDE.md)
- Avancement par lot : `docs/plan-lot-*.md`

## Démarrage

```bash
pnpm install
pnpm dev
```
